## 📊 任务1：美股2.0投资标的更新

### 基本信息

- **任务ID**：`cc97b4b3-c824-4b90-ba5b-598b65c5dc47`
- **Cron表达式**：`0 6 * * *`
- **执行时间**：每天早上6:00（冬令时）或5:00（夏令时3-11月）
- **对应时间**：美股收盘后1小时（美东时间17:00）

### 任务描述

自动更新美股投资标的2.0价格，使用优化的数据源架构获取32只股票的最新数据。

### 核心配置

**脚本路径**：`/data/workspace/scripts/update_stock_2.0_v4.py`

**数据文件**：`/data/workspace/stock_pool/美股投资标的_跟踪2.0.xlsx`

**股票清单**（32只）：
```
USAR, CRML, MP, NB, RIO, ATI, ALM, LTBR, CCJ, UUUU, 
LAC, ALB, NVX, WWR, GDX, GLD, NVA, SLV, FCX, RMBS, 
SNDK, MU, GOOG, PGY, INTC, NVDA, UMAC, ONDS, SHLD, 
XOVR, IBIT, ETHA
```

### 数据源架构（V4）

**优先级顺序**：
1. **富途 OpenAPI** (实时，<1秒延迟) - 需Mac本地运行
2. **yfinance 优化版** (15-30分钟延迟，95%+成功率) - 主要数据源
3. **Polygon.io** (历史数据，用于回测)

**智能 Fallback 机制**：
```python
优先级：富途 OpenAPI → yfinance → 标记失败
```

### 分析体系（2.0版本）

**29个指标字段**：
- **技术面**：RS相对强度、VAP筹码、趋势动量、ATR波动率
- **资金面**：机构持仓、筹码集中度
- **消息面**：分析师评级、市场情绪

**自动计算**：
- 总评分（0-100分）
- 价格区间判断（超买/合理/超卖）
- 操盘建议（买入/观望/减仓）
- 风险收益比2.0
- 执行优先级（A/B/C级）

### 新增功能（V4）

**指数跟踪**：
- 纳指 QQQ
- 标普 SPY

**市场环境判断**：
- 多头趋势（指数 > MA20 > MA50）
- 震荡趋势（指数在 MA20 附近波动）
- 空头趋势（指数 < MA20 < MA50）

**系统性风控**：
- 指数空头保护：自动降低个股评分
- 辅助波段操作决策

### 通知配置

**通知渠道**：企业微信「Knot消息通知」机器人

**通知内容**：
- ✅ 成功数量
- 🎯 A级推荐标的
- 👀 B级关注标的
- 📈 价格异动 TOP5
- ❌ 失败标的列表


### 手动触发任务

```python

```

### 暂停/恢复任务

```python
# 暂停任务（需要删除后重新添加）
from cron import remove_job
remove_job(job_id="任务ID")

# 重新添加任务
from cron import add_job
add_job(
    job_name="任务名称",
    cron_expression="0 6 * * *",
    job_message="任务描述"
)
```

```python
# 在旧 Claw 实例中执行
import json
from cron import list_jobs

jobs = list_jobs()
with open('/data/workspace/cron_jobs_export.json', 'w') as f:
    json.dump(jobs, f, indent=2)

print("✅ 定时任务配置已导出到: /data/workspace/cron_jobs_export.json")
```

### 导入到新 Claw 实例

```python
# 在新 Claw 实例中执行
import json
from cron import add_job

with open('/data/workspace/cron_jobs_export.json', 'r') as f:
    jobs = json.load(f)

for job in jobs:
    add_job(
        job_name=job['name'],
        cron_expression=job['cron_expression'],
        job_message=job['message']
    )
    print(f"✅ 已添加任务: {job['name']}")

print("\n✅ 所有定时任务已导入")
```
