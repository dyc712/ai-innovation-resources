## 🔧 故障排查

### 问题1：Git克隆失败

**症状**：`git clone` 失败或超时

**解决方案**：
```bash
# 检查网络连接
ping -c 3 github.com

# 使用HTTPS而不是SSH
git clone https://github.com/dyc712/ai-innovation-resources.git

# 如果仍然失败，检查代理设置
git config --global http.proxy ""
git config --global https.proxy ""
```

---

### 问题2：pip安装依赖失败

**症状**：`pip3 install` 失败或超时

**解决方案**：
```bash
# 使用清华镜像源
pip3 install -i https://pypi.tuna.tsinghua.edu.cn/simple pandas yfinance requests

# 或临时使用镜像
pip3 install --index-url https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt

# 单独安装失败的包
pip3 install pandas
pip3 install yfinance
```

---

### 问题3：定时任务创建失败

**症状**：Claw无法创建定时任务

**解决方案**：
```
检查cron工具是否可用：
"测试创建一个简单的定时任务：
任务名称：测试任务
Cron表达式：0 9 * * *
任务消息：这是一个测试任务，请使用notify工具通知我"

如果成功，删除测试任务，然后创建正式任务
```
