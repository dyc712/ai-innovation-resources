## 🔄 未来自动化方案

### 方案A：定时同步脚本（Mac本地）

创建 launchd 任务，每天自动从 GitHub 同步并上传到乐享：

```bash
# 创建自动化脚本
cat > ~/sync_investment_to_lexiang.sh << 'EOF'
#!/bin/bash
cd ~/ai-innovation-resources
git pull origin main

# 调用Clawdbot CLI上传文件（需要配置lexiang skill）
clawdbot chat "使用lexiang skill上传文件到乐享..."
EOF

chmod +x ~/sync_investment_to_lexiang.sh

# 配置launchd定时任务（每天早上9点）
cat > ~/Library/LaunchAgents/com.user.sync-investment.plist << 'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.user.sync-investment</string>
    <key>ProgramArguments</key>
    <array>
        <string>/bin/bash</string>
        <string>/Users/dongyunchuan/sync_investment_to_lexiang.sh</string>
    </array>
    <key>StartCalendarInterval</key>
    <dict>
        <key>Hour</key>
        <integer>9</integer>
        <key>Minute</key>
        <integer>0</integer>
    </dict>
    <key>StandardOutPath</key>
    <string>/tmp/sync-investment.log</string>
    <key>StandardErrorPath</key>
    <string>/tmp/sync-investment.error.log</string>
</dict>
</plist>
EOF

# 加载定时任务
launchctl load ~/Library/LaunchAgents/com.user.sync-investment.plist
```

### 方案B：GitHub Actions自动上传（高级）

在 GitHub 仓库配置 Actions，当文件更新时自动调用乐享 API 上传：

```yaml
# .github/workflows/sync-to-lexiang.yml
name: Sync to Lexiang

on:
  push:
    paths:
      - '08-投资跟踪/**'

jobs:
  upload:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Upload to Lexiang
        env:
          LEXIANG_APP_KEY: ${{ secrets.LEXIANG_APP_KEY }}
          LEXIANG_APP_SECRET: ${{ secrets.LEXIANG_APP_SECRET }}
        run: |
          python3 scripts/upload_to_lexiang_batch.py
```
