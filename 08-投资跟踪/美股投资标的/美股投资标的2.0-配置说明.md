## 系统概述

### 核心功能

本系统实现了**美股投资标的2.0专业分析体系**的自动化更新，包括：

- ✅ **真实数据接入**：通过Yahoo Finance API获取37只股票的实时行情
- ✅ **智能评分系统**：四维评分体系（技术面40% + 资金面40% + 消息面20%）
- ✅ **动态风控**：基于ATR的动态止损止盈计算
- ✅ **操盘建议**：根据评分和价格区间自动生成操盘策略
- ✅ **自动通知**：每日自动执行并通过企业微信推送更新报告

### 系统架构

```
定时任务触发 (每天21:00)
    ↓
执行更新脚本 (update_stock_2.0.py)
    ↓
Yahoo Finance API → 获取实时数据 → 计算2.0指标
    ↓
更新Excel文件 (美股投资标的_跟踪2.0.xlsx)
    ↓
生成分析报告 (Markdown格式)
    ↓
企业微信通知 (Knot消息机器人)
```

## 定时任务配置

### 基本信息

| 配置项 | 值 |
|--------|-----|
| **任务名称** | 美股投资标的2.0每日更新 |
| **任务ID** | `cc97b4b3-c824-4b90-ba5b-598b65c5dc47` |
| **执行时间** | 每天21:00（北京时间） |
| **Cron表达式** | `0 21 * * *` |
| **超时时间** | 10分钟 |

### 为什么选择21:00？

- 美东时间夏令时：21:00北京时间 = 09:00美东时间（开盘前30分钟）
- 美东时间冬令时：21:00北京时间 = 08:00美东时间（开盘前1.5小时）
- 覆盖全年，确保在开盘前获取前一交易日收盘数据

### 执行流程

1. **数据获取**（约3-5分钟）
   - 通过Yahoo Finance API获取37只股票数据
   - 每只股票间隔1秒请求（避免限流）
   - 失败自动重试3次

2. **指标计算**（约1分钟）
   - 技术面：RS相对强度、趋势动量、成交量信号
   - 资金面：机构持仓、筹码集中度
   - 消息面：分析师评级
   - 风控：动态止损止盈、风险收益比

3. **数据更新**（约30秒）
   - 更新Excel文件所有字段
   - 添加更新时间戳

4. **报告生成**（约10秒）
   - 生成Markdown格式分析报告
   - 识别A/B级推荐标的
   - 标注价格异动股票

5. **通知推送**（即时）
   - 通过企业微信Knot消息机器人发送
   - 包含完整更新报告和操盘建议

**优点**：
- ✅ 免费、无需API Key
- ✅ 数据全面（价格、成交量、机构持仓、分析师评级）

## 指标体系说明

### 四维评分体系（满分100分）

#### 1️⃣ 技术面（40分）

| 指标 | 权重 | 评分规则 |
|------|------|----------|
| **RS相对强度** | ±10分 | RS>10% = +10; 0<RS<10% = +5; RS<-10% = -10 |
| **VAP筹码分布** | ±10分 | 放量突破POC = +10; 缩量受阻 = -10 |
| **趋势动量共振** | ±10分 | 均线多头排列 = +10; 均线空头 = -10 |
| **基础分** | 20分 | 所有标的起始分 |

**计算公式**：
```
技术面得分 = 20 + RS评分 + VAP评分 + 动量评分
范围：[0, 40]
```

#### 2️⃣ 资金面（40分）

| 指标 | 权重 | 评分规则 |
|------|------|----------|
| **机构持仓变动** | ±15分 | 有机构持仓数据 = +10 |
| **筹码集中度** | ±15分 | 5日涨幅>0 = +5（简化） |
| **空头博弈潜力** | +10分 | 固定+5分（需接入做空数据） |
| **基础分** | 20分 | 所有标的起始分 |

**计算公式**：
```
资金面得分 = 20 + 机构评分 + 筹码评分 + 空头评分
范围：[0, 40]
```

#### 3️⃣ 消息面（20分）

| 指标 | 权重 | 评分规则 |
|------|------|----------|
| **催化剂评级** | ±10分 | A级催化剂=+10; C级利空=-10（需接入新闻） |
| **分析师共识** | ±5分 | 近期5个买入评级 = +10 |
| **市场情绪** | ±5分 | 需接入社交媒体数据 |
| **基础分** | 10分 | 所有标的起始分 |

**计算公式**：
```
消息面得分 = 10 + 催化剂评分 + 分析师评分 + 情绪评分
范围：[0, 20]
```

#### 🚫 宏观风控（一票否决）

| 风险因素 | 扣分 | 触发条件 |
|----------|------|----------|
| **US10Y飙升** | -10分 | 单周涨幅>5% |
| **现货价格破位** | -20分 | 矿业股现货价<MA60 |

### 综合评分公式

```
总评分 = 技术面×40% + 资金面×40% + 消息面×20% - 宏观惩罚
范围：[-30, 100]
```

### 操盘建议矩阵

| 总评分 | 价格区间 | RRR | 操盘建议 | 仓位 | 优先级 |
|--------|----------|-----|----------|------|--------|
| ≥80 | 买入狙击区 | ≥2.5 | 【强力买入】 | 60-80% | A级 |
| ≥80 | 加仓确认区 | ≥2.5 | 【追涨/加仓】 | 20% | A级 |
| 60-79 | 买入狙击区 | ≥2.5 | 【试探买入】 | 30-50% | B级 |
| 60-79 | 其他 | ≥2.5 | 【持有】 | 维持 | B级 |
| <60 或 RRR<2.5 | 任何 | 任何 | 【观望/卖出】 | 0% | C级 |

### 动态风控公式

**止损位计算**：
```
动态止损位 = 当前价 - (N × ATR)

N值设定：
- 稳健型（大盘股）：N = 1.5
- 激进型（矿业/核能/ASIC）：N = 2.5
```

**止盈位计算**：
```
第一止盈位（TP1）= 当前价 + (1.0 × ATR)
目标止盈位（TP2）= 当前价 + (2.5 × ATR)
```

**风险收益比**：
```
RRR = (TP2 - 当前价) / (当前价 - 止损位)

一票否决：RRR < 2.5 不做交易
```

## 故障排查

### 常见问题

#### 1. Yahoo Finance API限流

**症状**：
```
❌ Too Many Requests. Rate limited. Try after a while.
```

**原因**：
- 短时间内请求过于频繁
- Yahoo Finance服务器临时限流

**解决方案**：
- ✅ 已内置：每次请求间隔1秒
- ✅ 已内置：失败自动重试3次
- 如仍失败，等待1小时后手动重试
- 考虑切换到Alpha Vantage API（需API Key）

#### 2. 更新任务执行失败

**症状**：
- 企业微信收到"更新失败"通知
- Excel文件未更新

**排查步骤**：
```bash
# 1. 检查脚本是否存在
ls -la /data/workspace/scripts/update_stock_2.0.py

# 2. 检查Python环境
python3 -c "import pandas, yfinance; print('OK')"

# 3. 手动执行查看详细错误
python3 /data/workspace/scripts/update_stock_2.0.py
```

#### 3. 部分股票更新失败

**症状**：
- 报告中显示"更新失败标的：XXX, YYY"
- 成功率<100%

**原因**：
- 该股票已退市或暂停交易
- 股票代码错误
- 临时网络问题

**解决方案**：
- 检查股票代码是否正确
- 在Yahoo Finance网站验证股票是否可交易
- 下次更新会自动重试

#### 4. 企业微信未收到通知

**症状**：
- 任务执行成功但没有通知

**原因**：
- 定时任务中的notify调用失败
- 企业微信机器人配置问题

**解决方案**：
- 检查定时任务日志
- 向AI助手请求："测试企业微信通知"
