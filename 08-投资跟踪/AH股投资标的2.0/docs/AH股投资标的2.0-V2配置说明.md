## 📚 API文档参考

### 新浪财经API
```
接口: https://hq.sinajs.cn/list=代码列表
格式: GET请求，逗号分隔多个代码
限制: 单次最多50个代码
返回: GBK编码的纯文本
文档: 无官方文档（民间API）
```

### 东方财富API
```
接口: http://push2.eastmoney.com/api/qt/stock/get
格式: GET请求，参数secid
限制: 单个股票查询
返回: JSON格式
文档: 无官方文档（逆向工程）
```
