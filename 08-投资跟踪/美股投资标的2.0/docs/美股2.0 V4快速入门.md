## 📊 核心功能说明

### 1. 指数市场环境判断 ⭐

**自动获取**: QQQ + SPY

**环境信号**:
- 🟢 **强势多头** (信号≥0.75): 积极做多,个股评分+10分
- 🟡 **偏多环境** (信号≥0): 谨慎做多,个股评分+5分  
- 🟠 **震荡市** (信号≥-0.5): 控制仓位,评分不变
- 🔴 **弱势空头** (信号<-0.5): 强制观望,个股降至C级

**示例**:
```
QQQ: $450 | 多头排列 (+1.0)
SPY: $500 | 震荡偏多 (+0.5)
→ 平均信号: 0.75 → 🟢 强势多头,适合积极做多

个股NVDA:
  基础评分: 78分
  指数加分: +10分
  最终评分: 88分 → A级 【强力买入】
```

### 2. 指数空头保护机制 🛡️

**触发条件**: QQQ和SPY均为空头排列

**强制操作**:
- 所有个股降至C级
- 操盘建议: 【观望/减仓】
- 建议仓位: 0-20%

**目的**: 防止在指数弱势环境下重仓个股,控制系统性风险

## ❓ 常见问题

### Q1: 富途连接一直失败?
**A**: 正常,脚本会自动使用yfinance备用源。AnyDev开发机网络可能无法访问富途服务器。

### Q2: yfinance成功率低?
**A**: 
- 已优化至60秒超时
- 如果仍限流,编辑脚本增加请求间隔:
  ```python
  time.sleep(3)  # 改为3-5秒
  ```

### Q3: 指数数据失败影响大吗?
**A**: 
- 影响: 失去市场环境判断功能
- 个股评分仍可正常计算
- 建议: 检查yfinance网络连接

### Q4: 如何只更新指数,不更新个股?
**A**: 暂不支持,可以手动运行:
```python
python3 << EOF
import sys
sys.path.append('/data/workspace/scripts')
from update_stock_2.0_v4 import fetch_index_data
for ticker in ['QQQ', 'SPY']:
    data = fetch_index_data(ticker)
    print(data)
EOF
```
