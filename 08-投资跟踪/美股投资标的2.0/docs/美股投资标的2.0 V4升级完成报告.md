### 2. 指数跟踪功能 ⭐

#### 新增指数标的
- ✅ QQQ (纳斯达克100指数ETF)
- ✅ SPY (标普500指数ETF)
- ✅ 已添加到Excel文件中

#### 指数信号计算
```
技术面判断:
- 当前价格 > SMA20 > SMA60 → 多头排列 (+1.0)
- 当前价格 > SMA20 → 震荡偏多 (+0.5)
- 当前价格 < SMA20 < SMA60 → 空头排列 (-1.0)
- 其他 → 震荡 (0)
```

#### 市场环境评分
```
QQQ信号 + SPY信号 → 平均信号

平均信号 ≥ 0.75 → 🟢 强势多头 (+10分,积极做多)
平均信号 ≥ 0 → 🟡 偏多环境 (+5分,谨慎做多)
平均信号 ≥ -0.5 → 🟠 震荡市 (0分,控制仓位)
平均信号 < -0.5 → 🔴 弱势空头 (-10分,强制观望)
```

#### 指数空头保护机制 🛡️
```python
if 指数平均信号 < -0.5:
    # 强制降级,无视个股评分
    操盘建议 = "【观望/减仓】"
    建议仓位 = "0-20%"
    执行优先级 = "C级"
```

**作用**: 防止在指数弱势环境下重仓个股,控制系统性风险

## 📞 故障排查

### 问题1: 富途连接失败

```
ConnectionRefusedError: [Errno 111] Connection refused
```

**检查步骤**:
```bash
# 1. 检查FutuOpenD进程
ps aux | grep FutuOpenD

# 2. 如果没有,启动它
cd /data/workspace/tools/FutuOpenD_7.2.3308_Ubuntu16.04
./FutuOpenD &

# 3. 查看日志
tail -f futuopend.log

# 4. 测试连接
python3 << EOF
from futu import OpenQuoteContext
ctx = OpenQuoteContext(host='127.0.0.1', port=11111)
print("连接成功!")
ctx.close()
EOF
```

**如果仍失败**: 脚本会自动使用yfinance,不影响运行

### 问题2: 指数数据获取失败

```
❌ QQQ: 获取失败
```

**影响**: 失去市场环境判断功能

**解决**:
```bash
# 测试yfinance连接

import yfinance as yf
stock = yf.Ticker("QQQ")
hist = stock.history(period="5d")
print(f"QQQ价格: ${hist['Close'].iloc[-1]:.2f}")
EOF
```
