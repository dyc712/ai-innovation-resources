## ⚠️ 问题分析

### 问题1: Finnhub API连接超时 ⭐⭐⭐
**现象**:
```
Finnhub API错误: HTTPSConnectionPool(host='finnhub.io', port=443): 
Read timed out. (read timeout=5)
```

**原因分析**:
1. 超时设置过短（5秒）
2. AnyDev开发机网络延迟
3. Finnhub服务器响应慢
4. 可能需要代理访问

**解决方案**:
```python
# 方案1: 增加超时时间
response = requests.get(quote_url, timeout=15)  # 5秒 → 15秒

# 方案2: 添加重试装饰器
from requests.adapters import HTTPAdapter
from requests.packages.urllib3.util.retry import Retry

session = requests.Session()
retry = Retry(total=3, backoff_factor=1)
adapter = HTTPAdapter(max_retries=retry)
session.mount('https://', adapter)
```

### 问题2: 股票代码错误 ⭐⭐
**错误代码列表**:

| 当前代码 | 正确代码 | 说明 |
|---------|---------|------|
| SK海力士 | 000660.KS | 韩国股票，或使用ADR |
| GOOGLE | GOOGL | Alphabet Class A |
| 美光科技(MU) | MU | 直接使用代码，去掉中文 |
| SanDisk(SNDK) | 已退市 | 2016年被西部数据收购 |

**修正脚本**:
```python
# 在Excel中统一代码格式
错误: "美光科技(MU)" → 正确: "MU"
错误: "GOOGLE" → 正确: "GOOGL"
```

### 问题3: Yahoo Finance限流 ⭐
**现象**:
```

Try after a while.
```

**影响**: 约36%的股票无法获取数据

**缓解措施**:
- 已增加请求间隔至1.5秒
- 3次重试机制
