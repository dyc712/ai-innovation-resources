### 2. 新增指数跟踪功能 ⭐

#### 指数标的
- **QQQ**: 纳斯达克100指数ETF (科技股代表)
- **SPY**: 标普500指数ETF (大盘代表)

#### 指数信号计算
```python
# 趋势判断逻辑
if 当前价格 > SMA20 > SMA60:
    信号 = +1.0  # 多头排列,支持做多
elif 当前价格 > SMA20:
    信号 = +0.5  # 震荡偏多
elif 当前价格 < SMA20 < SMA60:
    信号 = -1.0  # 空头排列,避免做多
else:
    信号 = 0     # 震荡
```

#### 指数对个股评分影响

| 指数信号均值 | 指数加分 | 市场环境 | 建议操作 |
|------------|---------|---------|---------|
| ≥ 0.75 | +10分 | 🟢 强势多头 | 积极做多 |
| 0 ~ 0.75 | +5分 | 🟡 偏多环境 | 谨慎做多 |
| -0.5 ~ 0 | 0分 | 🟠 震荡市 | 控制仓位 |
| < -0.5 | -10分 | 🔴 弱势空头 | 避免做多,强制观望 |

**示例**:
```
个股基础评分: 75分
QQQ信号: +1.0 (多头排列)
SPY信号: +0.5 (震荡偏多)
平均信号: (1.0 + 0.5) / 2 = 0.75

最终评分: 75 + 10 = 85分 (升至A级)
```

#### 指数空头保护机制 🛡️

```python
# 强制降级逻辑
if 指数平均信号 < -0.5:  # 指数空头排列
    操盘建议 = "【观望/减仓】"
    建议仓位 = "0-20%"
    执行优先级 = "C级"
    # 忽略个股评分,强制保守
```

**作用**: 即使个股基本面优秀,指数空头时也避免重仓,防止系统性风险。

## 🔧 技术实现细节

### 1. 富途OpenAPI集成

#### 初始化连接
```python
from futu import OpenQuoteContext, RET_OK

quote_ctx = OpenQuoteContext(host='127.0.0.1', port=11111)
```

#### 获取实时报价
```python
futu_ticker = f"US.{ticker}"  # 转换格式: AAPL → US.AAPL
ret, data = quote_ctx.get_market_snapshot([futu_ticker])

if ret == RET_OK:
    current_price = data.iloc[0]['last_price']
    prev_close = data.iloc[0]['prev_close_price']
```

#### 获取历史K线
```python
from futu import KLType

ret, kline_data = quote_ctx.get_cur_kline(
    futu_ticker, 
    100,           # 获取100根K线
    KLType.K_DAY   # 日线
)
```

#### 使用限制
- **免费账户**: 最多同时订阅5只股票
- **证券账户**: 无限制订阅

**解决方案**: 优先级策略
```python
FUTU_PRIORITY_TICKERS = ['QQQ', 'SPY', 'NVDA', 'AAPL', 'TSLA']

# 核心标的用富途(实时性高)
# 其余标的用yfinance(覆盖全面)
```

### 2. yfinance优化版

#### Session模式 + 浏览器伪装
```python
import requests

session = requests.Session()
session.headers.update({
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) ...',
    'Accept': 'text/html,application/xhtml+xml,...',
    'Accept-Language': 'en-US,en;q=0.5',
    'Connection': 'keep-alive',
})

stock = yf.Ticker(ticker, session=session)
hist = stock.history(period="5d", timeout=60)  # 超时从5秒延长至60秒
```

#### 改进效果
| 指标 | V3版本 | V4优化版 |
|------|-------|---------|
| **超时设置** | 默认5秒 | 60秒 |

| **连接模式** | 每次新建 | Session复用 |
| **预期成功率** | 81% | 95%+ |

### 2. 个股风控（原有）

```python
# ATR动态止损
止损位 = 当前价格 - (N * ATR)

# N值根据分类调整
if 分类 in ['核能', '稀土', 'ASIC']:
    N = 2.5  # 高波动标的,更宽止损

    N = 1.5  # 一般标的
```
